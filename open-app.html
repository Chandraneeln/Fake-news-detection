How to Use the Application

  1. Click the button above to open the main application
  2. Once open, you can analyze content in three ways:
    • Enter text directly in the text box
    • Paste a URL to analyze web content
    • Upload an image containing text
  3. Click "Analyze" to receive a credibility score and detailed analysis
Note: For full functionality with real-time content analysis, you'll need to add your Google API key to the .env file in the backend directory. Refer to the .env.example file for guidance.
